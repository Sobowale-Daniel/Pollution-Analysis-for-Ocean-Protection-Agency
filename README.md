# Pollution-Analysis-for-Ocean-Protection-Agency
## Introduction
This project examines a dataset spanning 1944 to 2017, sourced from the Ocean Protection Agency, to identify factors contributing to rising pollution levels across various states and regions in the United States. It also highlights the most prevalent contaminants. The analysis encompasses the entire data analysis workflow, from problem identification and data exploration to insights visualization, demonstrating versatile problem-solving and analytical skills.
